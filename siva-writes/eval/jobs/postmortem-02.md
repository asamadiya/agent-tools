Raw material, Cloudflare, 18 November 2025 incident, downstream blast radius only, all times UTC. Workers KV returned heavily elevated 5xx because its front-end gateway calls the core proxy, which was failing. At 13:04 a patch let Workers KV bypass the core proxy; everything downstream of KV, including Access, saw error rates fall. Cloudflare Access saw widespread authentication failures from the start of the incident until the 13:05 rollback. Existing Access sessions kept working. Every failed authentication ended at an error page, so no user reached a target application while auth was broken, and successful logins during the window were logged correctly. Access configuration updates attempted during the window either failed outright or propagated very slowly; all have since been recovered. The Dashboard depends on Workers KV internally and on Turnstile in the login flow; Turnstile failed to load, so anyone without an active session could not log in. Dashboard availability dropped across two separate windows: 11:30 to 13:10, ended by the KV bypass at 13:10, and 14:40 to 15:30, caused by a backlog of queued login attempts plus retries after the feature file was restored, ended by scaling control plane concurrency around 15:30. Email Security kept processing and delivering mail but lost access to an IP reputation source, reducing spam-detection accuracy and suppressing some new-domain-age detections; some Auto Move actions failed and were later remediated. CDN response latency also rose because debugging and observability systems consumed large amounts of CPU enriching uncaught errors.
