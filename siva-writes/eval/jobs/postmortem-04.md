Raw material, Cloudflare, 20 February 2026, all times UTC. Outage began 17:48 and the last prefixes were restored at 23:03, 5 hours 15 minutes later. Customers using Bring Your Own IP saw their prefixes withdrawn via BGP. Of 6,500 prefixes advertised to a given peer, 4,306 are BYOIP; about 1,100 were withdrawn between 17:56 and 18:46, roughly 25% of all BYOIP prefixes. Affected customers hit BGP path hunting: connections keep searching for a route and hang until timeout. Visitors to the one.one.one.one website got HTTP 403 with an Edge IP Restricted message; DNS resolution over 1.1.1.1, including DNS over HTTPS, kept working. Root cause: a new cleanup sub-task meant to automate removal of BYOIP prefixes issued GET /v1/prefixes?pending_delete with no value. Query().Get("pending_delete") returned an empty string, so the API served every BYOIP prefix, and the sub-task treated all of them as queued for deletion, removing prefixes and their dependent service bindings until an engineer killed it. The Addressing API is the authoritative source for customer IP addresses and pushes changes to the edge immediately.
